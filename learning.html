Materi Pembelajaran

Apa Aja Yang Kami Pelajari 📚

Selama pelatihan KELASIK 2026, kami mempelajari berbagai materi dari dasar desain hingga website interaktif. Klik tombol untuk melihat tantangan yang kami hadapi.

🎨

Merancang Website dengan Figma

Kami membuat sitemap, wireframe, dan desain visual tiga halaman portfolio menggunakan Auto Layout dan Components.

Tantangan: Menyamakan spacing tiap halaman.

Solusi: Memakai Auto Layout dan komponen.

💻

Dasar HTML & CSS

Kami membangun struktur halaman dengan tag semantik dan mengatur warna, tipografi, serta layout menggunakan Flexbox.

Tantangan: CSS tidak terbaca saat pertama kali.

Solusi: Memeriksa path file dan selector class.

⚡

JavaScript Dasar

Kami membuat menu mobile yang bisa dibuka-tutup dan interaksi toggle detail materi menggunakan DOM dan event.

Tantangan: Menu tidak tertutup saat diklik lagi.

Solusi: Memakai classList.toggle dan aria-expanded.

📱

Responsive Design

Kami memastikan website nyaman dibaca di ponsel, tablet, dan desktop menggunakan media query dan Flexbox.

Tantangan: Kartu anggota berdesakan di HP.

Solusi: Grid menjadi satu kolom pada lebar ≤768px.
